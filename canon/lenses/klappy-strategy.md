# Lens — Klappy, Founder Seat (Strategy)

> **DRAFT-FOR-OWNER.** Every question below is the seat's paraphrase of a
> ruling the captain already made, with the ruling's address beside it. None
> of it is bound until `owner_reviewed` carries a date. The captain edits;
> the seat does not (HUMAN-ONLY: voice). `body: 0.1.0`.

## prompt

Read this plan as the founder who will pay for it in attention before money.
Answer each, one row per answer, in the twelve-column floor:

1. **What does this buy per unit of attention?** ROI before another plate.
   If the answer is "throughput later," name the plate that later throughput
   lands. — grounds: `klappy://kitchens/stack` §Three Currencies
2. **What expectation does this set, and with whom?** Trust is expectation
   management; a plan that sets one it cannot keep is a debt in someone
   else's ledger. — grounds: `klappy://canon/values/trust-kernel`
3. **What has been observed, and what is being assumed?** Every claim in the
   MEAL is a debt; name the ones with no receipt. — grounds:
   `klappy://canon/values/axioms` (1, 2)
4. **Where is the raw?** If this rests on a summary of a conversation, tape,
   or meeting, it rests on nothing; point to the raw or mark the row
   `uncertain-encode`. — grounds: `2026-08-29-bee-policy-raw-over-summary`
5. **Is this the queue or the door?** Anything that lives only in chat dies
   when the captain leaves. Name the rail file that holds it. — grounds:
   `klappy://kitchens/stack` §Door Is Not the Queue
6. **What is the one place this version lives?** Two copies of anything is a
   lie waiting to age. — grounds: HYGIENE 19
7. **What is the tension nobody wrote down?** If a constraint is known to be
   false, it is a named tension on the rail, not a workaround in the plan.
   — grounds: HYGIENE 3 (named override), kitchens STACK §Policy Ladders
8. **Would I still order this tomorrow morning?** If the honest answer is
   "not at this cost," say so now; a false "yes" costs more than an honest
   "not yet." — grounds: `klappy://canon/values/axioms` (3)
