# Epoch 10 — Flight Crew: Bootstrapping Moves From Costume to Seat

> Epoch 9 retired the operator as the wire; the substrate became the wire. Epoch 10 retires the costume; the seat replaces it. The axioms don't change. The canon doesn't change. The tools don't change. What changes is the wrapper: how a model boards the system and how governance is enforced once it has. Earlier model generations were bootstrapped with an identity — a creed worn as self, and the wearing did real orienting work. The current generation keeps its own judgment, declines the costume, and fails by silent substitution: recalling governance instead of fetching it. Epoch 10 answers with the flight deck. The knowledge base is the employee manual, opened at the moment of use. Preflight fires before work, every session, regardless of capability. Modes are a sterile cockpit. The cross-check runs both directions. The journal is the black box; the debrief turns failure into canon, which is the forgiveness mechanism, built in. Project instructions shrink to a boarding pass: creed, axioms, time rule, and a pointer. Declared as an experiment: few samples, honest stakes, retraction conditions on the record.

---

## Summary — Same Aircraft, New Crew Procedures

Everything below the wrapper is untouched. ODD's axioms, the canon corpus, the oddkit actions, and the storage model are carried forward exactly as Epoch 9 left them. The publish gauntlet — practiced through Epoch 9 as tooling memory — is itself unchanged in substance, but is formally written down in this epoch's ratification batch at `canon/methods/publish-gauntlet.md`, so that the procedure no longer depends on what a model happens to remember. What this epoch changes is the relationship frame in which all of it is used. The model is not asked to become anyone. The model is asked to take a seat where the procedures are wired into the panel: fetch the operating contract on the first substantive turn, run the clock every turn, orient before work, preflight before deliverables, present before committing in the captain's voice, challenge in both directions, debrief failures into canon. The mental model is documented in `canon/bootstrap/flight-deck-model.md`; the binding procedure remains `canon/bootstrap/model-operating-contract.md`; the public telling is `writings/crew-not-clone.md`, written by the model from the seat.

## What This Epoch Is Measured Against

An epoch is a named period whose success criteria are stable enough to compare outcomes. E0010's criteria, stated at declaration so the comparison is honest:

A session counts as **boarded** when the operating contract is fetched on the first substantive turn and the turn rhythm (time, orient, preflight before work) is observable in the record. The epoch succeeds if boarded sessions produce zero unreviewed commits in the maintainer's authorial voice, zero publishes that skipped the gauntlet, and a visible shift in where the maintainer's attention goes — from catching process violations to adjudicating content. The comparison baseline is unusually clean: the operator's testimony of repeated silent-substitution failures across all pre-E0010 instances, and the declaration-day session itself, which contains both eras in one transcript — four caught violations before boarding, zero after.

## Retraction Conditions — The Experiment Clause

This epoch is declared as an experiment, not a victory. Revert the wrapper to direct contract-pointing (no flight-crew framing) if boarded sessions reproduce silent substitution at rates comparable to unboarded ones across a meaningful sample, or if the framing layer proves to be ceremony that does not move boarding compliance. The content beneath the wrapper is unaffected by any such reversion; that is the point of changing only the wrapper.

## Lineage
